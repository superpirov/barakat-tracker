**Баракат** — мусульманское приложение-трекер для повседневной жизни: время намаза и компас киблы, аят дня из Корана, задачи и дела, отметки совершённых молитв со стриком, финансовый учёт с калькулятором закята, дневник благодарности и Pomodoro-фокус.

Всё работает **полностью офлайн**: ни аккаунта, ни сервера, ни интернета — все данные хранятся только на вашем устройстве.

---

## ✨ Возможности

### 🕌 Ибадат

- **Время намаза** — точный астрономический расчёт прямо на устройстве, без запросов к API.
  - Методы расчёта: **1 — Всемирная исламская лига (MWL)**, **5 — Umm al-Qura (Мекка)**.
  - **Высокие широты** — корректная обработка полярных дней/ночей методом «ночные доли» (night portion), поэтому время намаза корректно и на севере.
  - Геолокация через Capacitor или ручной ввод города/координат.
- **Компас киблы** — направление на Каабу по азимуту и датчику ориентации.
- **Отметки намазов** — 5 молитв в день, счётчик **стрика** и **полных дней** (когда отмечены все пять).
- **Чтение Корана** — постраничный просмотр: арабский текст и перевод Эльмира Кулиева, выбор суры и страницы.
- **Недельная сетка** — наглядная история намазов за 7 дней.

### 📋 Задачи

- Категории, приоритеты, поиск и фильтры.
- Отметки выполнения, всё сохраняется локально.

### 🏠 Главная

- **Аят дня** — ежедневный аят из локальной базы Корана (2 файла ≈ 2.8 МБ, работают без сети).
- Сводка дня: ближайший намаз, задачи, прогресс.

### 💰 Финансы

- **Калькулятор закята** — по нисабу и имуществу.
- **Расходы за месяц** с поддержкой валют: `USD`, `EUR`, `RUB`, `UAH`, `BYN`, `KZT`, `UZS` и других.

### 📖 Благодарность

- Дневник благодарности — короткие записи о том, за что вы благодарны сегодня.

### ⏱️ Фокус

- **Pomodoro 25 / 5** — тайм-бокс для работы, зикра или учёбы.

### 🔔 Фоновый сигнал о намазе

- Наступление времени намаза приходит **уведомлением со звуком** — даже при свёрнутом приложении.
- Отдельный канал уведомлений: в обычном режиме звучит мелодия азана, в беззвучном — приходит само уведомление (без звука, как и настроено на устройстве).
- Текст уведомления: `🕌 Намаз · 13:45` → *«Наступило время намаза: Зухр»*.
- Настройки (`📢`) позволяют включить/выключить напоминания и сменить метод расчёта — будильники пересоздаются автоматически.

### 🎨 Интерфейс

- Светлая и тёмная темы — **переключаются автоматически по времени суток**.
- Адаптивная вёрстка, работает и как **PWA** в браузере.

## 🧱 Технологии

| Слой | Что используется |
| --- | --- |
| UI и логика | Vanilla JS + CSS в одном файле [`index.html`](index.html) |
| Сборка | [Vite 8](https://vite.dev) + [`vite-plugin-pwa`](https://github.com/vite-pwa/vite-plugin-pwa) (service worker, офлайн-кэш) |
| Обёртка под Android | [Capacitor 8](https://capacitorjs.com) |
| Плагины | `@capacitor/geolocation`, `@capacitor/local-notifications` |
| Данные | `localStorage`, ключ `barakat.v1` |
| База Корана | [`public/database/chapterverse/`](public/database/chapterverse) — арабский текст и перевод |
| Звук азана | [`gen-sound.js`](gen-sound.js) → `android/app/src/main/res/raw/prayer.wav` |

> 💡 Архитектурная особенность: **папки `src/` нет** — весь интерфейс и логика живут в одном `index.html` (~2400 строк). Это осознанное решение: приложение легко открыть, отредактировать и запустить где угодно, а Capacitor и Vite лишь упаковывают его в APK и PWA.

## 📥 Установка

### Готовый APK

Скачайте последнюю версию из раздела [Releases](https://github.com/superpirov/barakat-tracker/releases) и установите на Android 6.0 и выше.

1. Разрешите установку из «неизвестных источников».
2. Установите `Баракат-tracker-*.apk`.
3. Откройте приложение и укажите своё местоположение.

### Как PWA

Приложение собирается в статический сайт в `dist/` — его можно отдавать с любого хостинга и добавлять на домашний экран браузера.

## 🔔 Настройка уведомлений на Android

Чтобы сигнал о намазе гарантированно срабатывал в фоне:

1. При первом запуске разрешите **уведомления**.
2. **Настройки → Приложения → Баракат → Уведомления → Намаз** — убедитесь, что канал включён и задана важность.
3. **Настройки телефона → Приложения → Особый доступ → Будильники и напоминания** — разрешите для «Баракат» (иначе точные будильники могут не сработать).
4. В разделе «Батарея» отключите оптимизацию энергосбережения для приложения — это повышает надёжность фоновых срабатываний на некоторых прошивках.

## 🛠 Сборка из исходников

### Требования

- **Node.js** 20+ (проверено на 24)
- **JDK 21** (для Android-сборки)
- **Android SDK** с `compileSdk 36`, `minSdk 24`

### Шаги

```bash
# 1. Установка зависимостей
npm install

# 2. Сборка веб-части в dist/
npm run build

# 3. Синхронизация с Android-проектом
npx cap sync android

# 4. Сборка релизного APK
cd android
export JAVA_HOME="/путь/к/jdk-21"
./gradlew assembleRelease --console=plain
```

Готовый APK: `android/app/build/outputs/apk/release/app-release.apk`

<details>
<summary><b>Debug-сборка и SoundCloud-режим разработки</b></summary>

```bash
cd android && ./gradlew assembleDebug          # debug APK
npm run dev                                    # Vite dev-сервер
npm run preview                                # предпросмотр собранного dist/
```

</details>

<details>
<summary><b>Генерация звука азана</b></summary>

Мелодия `prayer.wav` (~4 секунды, 3-нотная фраза с реверберацией) генерируется процедурно:

```bash
node gen-sound.js android/app/src/main/res/raw/prayer.wav
```

Готовый файл лежит в репозитории, перегенерировать нужно только если захотите сменить мелодию.

</details>

## 📁 Структура проекта

```
barakat-tracker/
├── index.html                     # Всё приложение: UI + логика
├── vite.config.js                 # Сборка + PWA

│   ├── database/chapterverse/     # Коран: арабский + перевод (офлайн)

│   └── app/src/main/res/raw/prayer.wav
└── dist/                          # Результат npm run build
```

## 🔒 Приватность

- **Нет аккаунтов, серверов и аналитики.**
- Все данные — задачи, намазы, финансы, заметки — хранятся в `localStorage` вашего устройства.
- Геолокация используется только для расчёта времени намаза и не покидает телефон.
- Для полного сброса достаточно очистить данные приложения.
